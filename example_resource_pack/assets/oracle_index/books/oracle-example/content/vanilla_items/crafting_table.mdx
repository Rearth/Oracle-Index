The **crafting table** is an existing block item. Its page demonstrates that a
content entry can describe a placeable block just as easily as a handheld item.

Place it in the world and interact with it to open the familiar 3 by 3 crafting
grid. No custom image is required: Oracle Index obtains the item appearance from
Minecraft's live item registry.
