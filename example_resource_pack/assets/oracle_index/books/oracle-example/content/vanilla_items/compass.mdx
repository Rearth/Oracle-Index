The **compass** is a vanilla item that normally points toward the world spawn.
After being linked to a lodestone, it instead points to that lodestone while it
is used in the matching dimension.

This page is associated with `minecraft:compass`, so Oracle Index can discover
it as documentation for the actual item.

See also the [Crafting Table](@minecraft:crafting_table) and
[Diamond Pickaxe](@minecraft:diamond_pickaxe) examples.
