# A normal documentation page

Welcome! This small book demonstrates a **normal documentation page** in
Oracle Index. Markdown headings, **bold text**, *italic text*, and lists are all
available.

## A short checklist

- Switch between the **Docs** and **Content** tabs in the sidebar.
- Open the Compass, Crafting Table, and Diamond Pickaxe entries.
- Click this [Compass content-page link](@minecraft:compass).
- Hover the real item shown below.
